# わざでポケモン当てゲーム

スカーレット・バイオレット(DLC含む)に登場するポケモンを、覚えるわざから特定するゲームです。
**遊ぶ: https://uruurus15.github.io/pokemon-move-quiz/**

静的ファイルのみで動作します。ローカルで遊ぶ場合は `index.html` をブラウザで開いてください。

## モード
- **モードA: わざの組み合わせで特定する** — お題のポケモンが提示されます。そのポケモンが覚えるわざから複数を選び、詳細検索(AND条件)の結果をお題の進化系統(とドーブル)だけに絞れれば成功です。最小個数の表示、ヒント(わざ1個)、答えボタンがあります。お題は自分で指定することもできます。
- **モードB: 質問して当てる** — 隠されたポケモンに「このわざを覚える?」と質問し、答えを当てます。

進化前後など、わざだけでは区別できない同じ進化系統のポケモンは正解として扱います。ドーブル(全わざを覚える扱い)は、モードAでは検索結果に必ず残るため許容しますが、モードBでは不正解です。

## データの再生成
`node tools/build-data.mjs` で PokeAPI から `data.js` を作り直します(`tools/.cache` にキャッシュ)。
